# Oxeron VPN Clone (اندروید) — نسخه پنل سنایی (x-ui)

این پروژه یه اسکلت اپ اندروید (Kotlin + Jetpack Compose) هست که:
- ظاهرش شبیه اسکرین‌شات‌های ارسالی‌ته
- با یوزر/پس **ادمین** مستقیم به پنل سنایی (x-ui) تو لاگین می‌کنه
- لیست اینباندهای پنل رو می‌گیره و به عنوان لیست سرور نشون می‌ده
- برای اتصال واقعی از موتور **Xray-core** استفاده می‌کنه

## ⚠️ نکته امنیتی مهم
یوزرنیم/پسورد ادمین پنل مستقیم داخل اپ وارد و استفاده میشه. این روش فقط برای
**استفاده شخصی خودت** مناسبه. اگه بعداً خواستی این اپ رو بین کاربرای دیگه پخش کنی،
هرگز پسورد ادمین رو بهشون نده — به جاش باید یه لایه API واسط بسازی که هر کاربر
فقط به سرور/کانفیگ خودش دسترسی داشته باشه، نه به کل پنل.

## چطور بازش کنم؟
1. Android Studio (Koala یا جدیدتر) رو نصب کن.
2. پوشه `oxeron-clone` رو باز کن؛ Gradle خودش وابستگی‌ها رو دانلود می‌کنه (نیاز به اینترنت).
3. روی گوشی/امولاتور اندروید ۸+ اجرا کن.

## چیزی که هنوز باید خودت اضافه کنی: موتور واقعی Xray

الان اپ می‌تونه:
- ✅ به پنل لاگین کنه
- ✅ لیست اینباندها رو بگیره و پارس کنه (VLESS / VMess)
- ✅ از روی هر اینباند یه کانفیگ کامل JSON برای Xray بسازه
- ❌ ولی هنوز واقعاً تونل رو بالا نمی‌آره — چون کتابخونه Xray-core یه فایل باینری
  کامپایل‌شده از Go (`.aar`) هست که من نمی‌تونم اینجا برات بسازم.

### قدم‌های لازم:
1. یکی از این‌ها رو بگیر:
   - https://github.com/XTLS/libXray (رسمی‌تر، جدیدتر)
   - یا از سورس اپ متن‌باز v2rayNG / NekoBox الگو بگیر (خودشون Xray-core رو باندل کردن)
2. فایل `.aar` رو بذار توی `app/libs/libXray.aar`
3. توی `app/build.gradle.kts` این خط رو از حالت کامنت دربیار:
   ```
   implementation(files("libs/libXray.aar"))
   ```
4. توی `vpn/XrayManager.kt` دو تا متد `runXrayCore()` و `stopXrayCore()` رو با
   متدهای واقعی همون کتابخونه پر کن (مثلاً چیزی شبیه `Libv2ray.startV2rayPoint(configJson)`).
5. توی `vpn/OxeronVpnService.kt` باید طبق نمونه‌ی همون کتابخونه، TUN interface
   واقعی رو با `establish()` بسازی و ترافیکش رو به Xray-core وصل کنی
   (این بخش معمولاً یه نمونه‌ی آماده توی هر کتابخونه داره — کپی/تطبیقش بده).

## اگه مسیرهای API پنل تو فرق داره
فایل `network/XuiApiService.kt` رو باز کن — مسیرهای `login` و
`panel/api/inbounds/list` مطابق نسخه‌های رایج x-ui/3x-ui هستن. اگه پنلت یه فورک
دیگه‌ست و مسیرهاش فرق داره، فقط کافیه این دوتا Path رو تغییر بدی.

## ساختار پروژه
```
app/src/main/java/com/example/vpnapp/
  MainActivity.kt              -> فقط ناوبری بین صفحات
  AppViewModel.kt               -> state، لاگین، اتصال/قطع
  network/XuiApiService.kt      -> تماس Retrofit با پنل (login + inbounds list)
  network/XuiRepository.kt      -> پارس کردن پاسخ پنل به لیست سرور قابل استفاده
  network/XrayConfigBuilder.kt  -> ساخت کانفیگ JSON کامل Xray از روی هر اینباند
  vpn/XrayManager.kt            -> مدیریت وصل/قطع (نیاز به تکمیل با .aar واقعی)
  vpn/OxeronVpnService.kt       -> سرویس پس‌زمینه VPN
  ui/screens/                   -> صفحات Login / Home / ServerList
  ui/theme/                     -> رنگ‌ها و تم تیره مشابه عکس‌ها
```
